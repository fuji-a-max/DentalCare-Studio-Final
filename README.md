# DentalCare Studio — publishing notes

This release includes patient and treatment editing/deletion, treatment status changes, encrypted storage, recovery-code password reset, path-safe static files, and a Windows single-instance lock.

## First launch
Choose a password of at least 8 characters. The app displays a recovery code once. Store it offline; it is the supported password-recovery mechanism. There is intentionally no hidden master password/backdoor.

## Build
Run `BUILD_WINDOWS.bat` on Windows while connected to the internet. The EXE is `dist\\DentalCare Studio.exe`. The target PC needs Microsoft Edge WebView2 Runtime.

## Copying and resale
A PyInstaller EXE can technically be copied. No offline software can reliably prevent copying because the customer controls the computer. This repository includes an MIT license because it was created as a public repository; replace it with a commercial/proprietary license and add your business identity before selling. For real activation and resale control, use a server-side signed license service and consult a lawyer. Do not rely on a hard-coded master key or hardware fingerprint as a security boundary.

The included font CSS prefers Manrope and DM Sans when installed and uses a consistent system fallback when they are not. To guarantee identical rendering, add properly licensed `.woff2` files under `static/fonts/` and update `styles.css`; font binaries are not generated by this repository.
